# Developers

Resources for developers working with the Zyntex platform.

## API Documentation

Learn how to integrate with Zyntex APIs:

- **REST API**: HTTP endpoints for managing games, players, and moderations
- **WebSocket API**: Real-time updates and live data streams
- **SDK**: Pre-built libraries for popular platforms

## Authentication

All API requests require authentication using bearer tokens:

```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  https://api.zyntex.dev/games
```

## Rate Limiting

API endpoints are rate limited to ensure fair usage:

- **Free**: 1,000 requests/hour
- **Pro**: 10,000 requests/hour  
- **Enterprise**: Custom limits

## SDKs

Official SDKs are available for:

- **Roblox**: Lua SDK for game integration
- **JavaScript**: Node.js and browser support
- **Python**: Server-side integrations

## Webhooks

Set up webhooks to receive real-time notifications:

- Player events (join, leave)
- Moderation actions
- System alerts
- Custom events
