# Logs

Learn how to view, filter, and manage logs in your Zyntex dashboard.

## Overview

Logs provide detailed information about what's happening in your game servers. You can use logs to debug issues, monitor player activity, and track system events.

## Log Types

- **Chat**: Player chat messages
- **System**: Server system events
- **Error**: Error messages and exceptions
- **Custom**: Custom logs from your game scripts

## Viewing Logs

Access logs through the Zyntex dashboard:

1. Navigate to your game
2. Go to the "Logs" section
3. Use filters to find specific log entries

## Log Retention

Log retention varies by plan:
- **Free**: 7 days
- **Pro**: 30 days
- **Enterprise**: 90 days
