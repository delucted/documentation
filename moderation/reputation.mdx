# Player Reputation

The reputation system helps you identify problematic players and maintain a healthy game environment.

## Reputation Levels

### Clean
- New players or players with no moderation history
- Default reputation level
- Full access to game features

### Suspect  
- Players with minor infractions
- May have temporary restrictions
- Flagged for closer monitoring

### Offender
- Players with serious or repeated violations
- Significant restrictions applied
- Requires manual review for reputation improvement

## How Reputation Changes

Reputation is automatically calculated based on:

- **Moderation Actions**: Bans, mutes, and kicks affect reputation
- **Report Frequency**: Players who are frequently reported
- **Severity**: More serious violations have greater impact
- **Time Decay**: Old infractions have less weight over time

## Using Reputation

You can use reputation to:

- **Auto-moderate**: Automatically restrict suspect/offender players
- **Prioritize Reports**: Focus on reports from clean players
- **Custom Logic**: Implement reputation-based game features
- **Analytics**: Track player behavior trends

## Configuration

Reputation thresholds can be customized in your dashboard:

1. Go to Moderation settings
2. Configure reputation rules
3. Set automatic actions for each level
4. Test with your player base
